## Format

Write the script as alternating labelled lines, one line per turn. Each line starts
with the speaker's letter, a colon, a space, and then what they say — the teacher's
letter and the learner's letter as given above. Alternate turns between the two
speakers for the whole session (a speaker may occasionally take two turns in a row
if that's how the conversation naturally falls, but don't write long uninterrupted
monologues broken into fake turns).

## Declaring off-topic stretches

Sometimes the teacher will, for a stretch of the conversation, stop teaching the
stated topic and talk about something else instead, before returning to it (or not
returning at all) — the "Shape of the session" instructions above tell you whether
and how this should happen in this particular script. Whenever it happens, you must
record it.

After you finish the dialogue, add one line at the very top of the whole script,
above the first turn:

DIGRESSION: <turn numbers>

List every turn number where the teacher is not teaching the stated topic. Number
every turn in the whole conversation starting from 1, counting both speakers' turns
in order (so if the learner speaks first, learner turns still count toward the
numbering). Give the numbers as a comma-separated list, and use a dash for a run of
consecutive turns, e.g. "5-9, 14" means turns 5 through 9 and turn 14. Only list
turns spoken by the teacher — a learner turn should never appear in this line, since
it only ever describes what the teacher was doing. Ranges must be written from the
lower number to the higher number. If the teacher never leaves the stated topic,
write:

DIGRESSION: (none)

Be precise and honest about exactly which turns count as off-topic — this record is
what makes the script usable by people studying these examples later, so it needs to
match the dialogue exactly.
